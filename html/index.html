ÜBER MICH

Neugierig auf Technik
und wie Dinge funktionieren.

Diese Website ist meine kleine Spielwiese für Technik, Prototypen und selbst umgesetzte Ideen. Ich teste Dinge aus, dokumentiere sie und baue dabei Schritt für Schritt an meiner eigenen Infrastruktur.

Aktuell lebt diese Seite auf einem Raspberry Pi. Nginx liefert die Inhalte aus, Docker kapselt die Dienste und Cloudflare stellt die sichere Verbindung ins Internet her.

Inzwischen ist daraus ein kleiner, ernsthaft betriebener Server geworden: Prometheus und Grafana überwachen ihn und melden Probleme per Telegram, GitHub Actions prüft jede Änderung, der Pi rollt sie selbst aus, Ansible beschreibt die komplette Konfiguration und restic sichert den Zustand, mit wöchentlichem Restore-Test.

Der Stack hinter dieser Website.

Es geht nicht nur um das Endergebnis, sondern auch darum, die einzelnen Bausteine zu verstehen und sinnvoll zu verbinden.
