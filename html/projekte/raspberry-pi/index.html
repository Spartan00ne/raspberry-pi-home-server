PROJEKT 01 · RASPBERRY PI

Mein eigener Webserver.

Diese Website läuft nicht auf einem klassischen Webhosting- Paket, sondern auf einem Raspberry Pi bei mir zu Hause. Von der Hardware über Docker und Nginx bis zur sicheren Verbindung ins Internet habe ich die komplette Infrastruktur selbst aufgebaut.

Projekt läuft

Eine kleine Infrastruktur für eine kleine Website.

1x Raspberry Pi
3x Docker Container
1x Domain
1x Externe Festplatte

ARCHITEKTUR

Vom Raspberry Pi ins Internet.

Der Raspberry Pi ist nicht direkt aus dem Internet erreichbar. Stattdessen stellt Cloudflare einen Tunnel zum lokalen Webserver her.

WEB SERVER

nginx-homepage

Der Nginx-Container liefert die statischen Dateien der Website aus. Das eigentliche Website-Verzeichnis wird vom Raspberry Pi als read-only Volume eingebunden.

./html
☁️

TUNNEL

cloudflared

Der Cloudflare-Tunnel-Container stellt die Verbindung zwischen Cloudflare und dem lokalen Nginx-Container her.

http://nginx-homepage:80
📊

API

dashboard-api

Die Flask-API stellt die Live-Systemdaten für das Dashboard bereit. Sie läuft mit Gunicorn auf Port 8080.

/api/status
docker-compose.yml 
services:

  nginx-homepage:
    image: nginx:latest
    container_name: nginx-homepage
    restart: unless-stopped

  cloudflared:
    image: cloudflare/cloudflared:latest
    container_name: cloudflared
    restart: unless-stopped

  dashboard-api:
    build:
      context: ./api
    container_name: dashboard-api
    restart: unless-stopped
    expose:
      - "8080"

networks:
  web:

DOMAIN

koffler-online.de

Aus dem ursprünglichen Test mit einem temporären Cloudflare-Tunnel wurde schließlich eine eigene Domain.

Die DNS-Verwaltung liegt bei Cloudflare und der Datenverkehr wird über den Tunnel zu meinem Raspberry Pi weitergeleitet.
